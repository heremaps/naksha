# Naksha AI Skills

This branch contains only shared AI skills and instructions for Naksha. It does
not contain application source code and has an independent history from the
development branches.

- `skills/` contains one directory per AI skill, each with a `SKILL.md`.
- `skills/naksha-common/SKILL.md` contains the shared Naksha workspace instructions.

See `CHECKOUT.md` on `v3` for linking these skills into a local Naksha workspace.

The initial skills and instructions were copied from the `v3-naksha-33` branch.
